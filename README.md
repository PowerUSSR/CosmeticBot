# CosmeticBot

NPC-бот "модельер" для Paper/Spigot 1.20 на сервере **VortexiaPolit** — продаёт косметические предметы и внешний вид персонажа.

## Команда

`/cosmeticbot <spawn|skin|info>` — право `cosmeticbot.admin` (по умолчанию только ОП).

## Зависимости

- **Vault** (обязательно)
- **ProtocolLib** (обязательно)
- **ItemsAdder** (опционально)

## Сборка

```
build.bat
```
